# LUKPAD HAND MADE – โครงแอปร้านลูกปัดแฮนด์เมด

เปิด `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้องติดตั้งอะไร) — คนทั่วไป **ดูสินค้าได้โดยไม่ต้องเข้าสู่ระบบ** แต่ต้องลงทะเบียนก่อนจึงสั่งซื้อได้
บัญชีทดลอง: admin@lukpad.com / admin1234 · hello@gmail.com / 1234

## โครงสร้างไฟล์
```
lukpad-shop/
├── index.html              หน้าเดียว โหลด CSS/JS ตามลำดับด้านล่าง
├── css/style.css           สี ฟอนต์ เลย์เอาต์ (แก้สีแบรนด์ที่ตัวแปร :root)
├── js/
│   ├── config.js           ค่าคงที่: ขั้นสถานะคำสั่งซื้อ, ตัวเลือก Custom, ค่า Custom, ข้อมูลตั้งต้น (สินค้า/บัญชีธนาคาร)
│   ├── store.js            ชั้นข้อมูล (ตอนนี้ localStorage) <- จุดที่ต้องเปลี่ยนเมื่อต่อฐานข้อมูลจริง
│   ├── utils.js            state ของแอป, helper (esc, baht, toast, go, pImg, shrinkImage)
│   ├── views-auth.js       เมนูบน + หน้าเข้าสู่ระบบ/สมัครสมาชิก
│   ├── views-customer.js   สินค้า, รายละเอียด+Custom, ตะกร้า, ชำระเงิน/แนบสลิป, คำสั่งซื้อ, บัญชี
│   ├── views-admin.js      จัดการคำสั่งซื้อ/สถานะ/เลขพัสดุ, จัดการสินค้า (+ภาพสินค้า), สมาชิก, หน้าซิงก์ชีต
│   ├── sheet.js            ซิงก์สมาชิก/สินค้า/คำสั่งซื้อกับ Google Sheet ผ่าน Apps Script (ขึ้น/ลง + ดึงอัตโนมัติ)
│   └── app.js              router (กันลูกค้าเข้าหน้าแอดมิน) + event ทั้งหมด (click/change/submit)
├── gs/Code.gs              สคริปต์ Apps Script ที่ต้องวางในสเปรดชีต (มีฟังก์ชัน setup สร้างแท็บ/หัวคอลัมน์/คู่มือให้เอง)
└── db/
    ├── schema.sql          โครงฐานข้อมูล MySQL 7 ตารางตามรายงาน
    └── sheet-template/     ไฟล์หัวคอลัมน์ (CSV) สำหรับสร้างสเปรดชีตเองแบบ copy/paste
```
ลำดับ `<script>` ใน index.html สำคัญ (config → store → utils → views → sheet → app)

## สิทธิ์การใช้งาน 3 ระดับ
| ใคร | ทำอะไรได้ |
|---|---|
| **ผู้เยี่ยมชม** (ยังไม่ลงทะเบียน) | ดูหน้าร้านและรายละเอียดสินค้าได้ทุกชิ้น · **ซื้อไม่ได้** (หน้ารายละเอียดจะขึ้นปุ่ม “เข้าสู่ระบบ / สมัครสมาชิก” แทนปุ่มเพิ่มลงตะกร้า) · เมนูมีแค่ ดูสินค้า + เข้าสู่ระบบ |
| **ลูกค้า** (ลงทะเบียน/เข้าสู่ระบบแล้ว) | เพิ่มลงตะกร้า สั่งซื้อ แนบสลิป ดูคำสั่งซื้อของตัวเอง แก้ที่อยู่ |
| **แอดมิน** | จัดการคำสั่งซื้อ/สถานะ/เลขพัสดุ, จัดการสินค้า+ภาพ, ดูสมาชิก, ซิงก์ชีต (เข้าไม่ได้ถ้าไม่ใช่ admin) |

โค้ดที่คุมสิทธิ์: `app.js` (`BROWSE`, `ADMIN_ONLY`, `render()`) และการเช็กใน submit (`f-add`, `f-checkout`, `f-prod`) + `nav()` ใน `views-auth.js`

## นำขึ้นออนไลน์ (ให้ลูกค้าเปิดใช้ได้)
เว็บนี้เป็นไฟล์ static เอาไป host ฟรีได้เลย เลือกวิธีใดวิธีหนึ่ง:
1. **Netlify Drop** — เปิด https://app.netlify.com/drop แล้วลากทั้งโฟลเดอร์ `lukpad-shop` ไปวาง (ได้ลิงก์ทันที ไม่ต้องสมัครก็ได้)
2. **GitHub Pages** — อัปโฟลเดอร์ขึ้น repository → Settings → Pages → Branch: main / root → รอ 1 นาทีจะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`
3. **Vercel / Cloudflare Pages** — import repo แล้ว deploy (ไม่ต้องตั้ง build command)

หลัง deploy ให้แก้ `js/config.js` ตั้งค่า `SHEET_URL` เป็น Web App URL ของคุณ แล้ว deploy ใหม่ — **ทุกเครื่อง/ลูกค้าทุกคนจะซิงก์กับชีตเดียวกัน** (ถ้าไม่ตั้ง ทุกคนจะเห็นข้อมูลตั้งต้นคนละชุด เพราะข้อมูลเก็บใน localStorage ของแต่ละเบราว์เซอร์)

> หมายเหตุ: เปิดจากไฟล์ในเครื่อง (`file://`) บางเบราว์เซอร์บล็อกการเชื่อมต่อชีต แนะนำให้ใช้ผ่านเว็บ (https) เสมอ

## สลิปโอนเงิน (ให้แอดมินเปิดดูได้)
- ลูกค้าแนบสลิปที่หน้าคำสั่งซื้อ (สถานะ “รอชำระเงิน”) → ระบบย่อรูปเก็บไว้ในเครื่องเป็น base64 และ **แสดงรูปสลิปให้แอดมินดูในใบสั่งซื้อทันที** (คลิกรูป = เปิดเต็ม / กด “เปิดสลิปขนาดเต็ม” หรือ “ดาวน์โหลดสลิป”)
- แอดมิน → จัดการคำสั่งซื้อ มีป้ายสรุป “รอชำระเงิน N · แนบสลิปแล้ว N” และปุ่ม **แสดงเฉพาะที่มีสลิป**
- ลูกค้าเห็นสลิปที่ตัวเองแนบ และแนบใหม่ทับได้ตราบใดที่สถานะยังเป็น “รอชำระเงิน” (เปลี่ยนสลิปเองไม่ได้หลังแอดมินอัปเดตสถานะ)
- กด ⬆ อัปโหลดขึ้นชีต → สลิปเข้า Google Drive โฟลเดอร์ `lukpad-slips` แล้วนำลิงก์ไปใส่คอลัมน์ `slip_image` ของแท็บ **ORDERS** และ **PAYMENTS** (ชื่อไฟล์อยู่ใน `slip_name` / `receipt_no`) — คลิกที่เซลล์ในชีตก็เปิดดูรูปได้ และแอปจะเปลี่ยนจาก base64 เป็นลิงก์ Drive ให้เอง (ประหยัดพื้นที่เก็บของเบราว์เซอร์) · จะใช้โฟลเดอร์ที่สร้างไว้เองก็ได้ ดูหัวข้อ “โฟลเดอร์รูปใน Google Drive” ด้านล่าง
- ถ้าชีตเดิมยังไม่มีคอลัมน์ `slip_name`/`slip_image` ไม่ต้องทำอะไร สคริปต์จะเพิ่มให้อัตโนมัติเมื่อ push (หรือจะรัน `setup()` อีกครั้งก็ได้)
- **ดูสลิปในชีตได้เลย ไม่ต้องคลิก:** แท็บ ORDERS และ PAYMENTS มีคอลัมน์ **`slip_preview`** ที่เป็นสูตรแสดงรูป (`=IMAGE`) ให้เปิดชีตแล้วเห็นรูปสลิปในเซลล์ทันที (แถวถูกปรับความสูงให้เห็นรูป) — คอลัมน์ `slip_image` เก็บลิงก์จริงที่แอปใช้ · รูปสินค้าก็มี `product_image_preview` ในแท็บ PRODUCTS · ปิด/ปรับขนาดได้ที่ตัวแปร `PREVIEW` ใน `gs/Code.gs` (ห้ามพิมพ์ทับคอลัมน์ `*_preview` เอง เพราะสคริปต์เขียนสูตรใหม่ทุกครั้งที่ซิงก์)
- คำสั่งซื้อที่แนบสลิปไว้ “ก่อน” อัปเดตนี้จะเก็บแค่ชื่อไฟล์ (เปิดรูปไม่ได้) — ให้ลูกค้าแนบสลิปใหม่ ระบบจะแสดงข้อความแจ้งไว้ที่ใบสั่งซื้อนั้น

## ภาพสินค้า

- ยังไม่ได้กดซิงก์ รูปจะถูกเก็บเป็น base64 ใน localStorage ของเครื่องนั้น ๆ
- กด “อัปโหลดขึ้นชีต” รูปจะเข้า Google Drive (โฟลเดอร์ `lukpad-images`) แล้วนำลิงก์ไปใส่ในคอลัมน์ `product_image` ของแท็บ PRODUCTS อัตโนมัติ

## โฟลเดอร์รูปใน Google Drive (ใช้โฟลเดอร์ที่สร้างไว้เอง)
ปกติสคริปต์จะสร้างโฟลเดอร์ `lukpad-images` (รูปสินค้า) และ `lukpad-slips` (สลิป) ให้เอง แต่ถ้าคุณสร้างโฟลเดอร์ไว้ก่อนแล้ว ให้ผูกด้วย **Folder ID** เพื่อไม่ให้สคริปต์ไปสร้างโฟลเดอร์ซ้ำ:

1. เปิดโฟลเดอร์ใน Google Drive → คัดลอก ID จากลิงก์ `https://drive.google.com/drive/folders/`**`1bNa8AbI-92b9MoiEa-9YMJWr83ON26G_`**
2. เปิด `gs/Code.gs` → แก้ตัวแปร `FOLDERS` (อยู่เหนือฟังก์ชัน `folder_`) แล้ววาง ID ลงช่อง `id`

```js
const FOLDERS = {
  images: { id: "",                                    name: "lukpad-images" },  // รูปสินค้า
  slips:  { id: "1bNa8AbI-92b9MoiEa-9YMJWr83ON26G_",   name: "lukpad-slips" }    // สลิปโอนเงิน
};
```

- `id` มีสิทธิ์เหนือ `name` เสมอ · ถ้า `id` ว่างหรือเปิดไม่ได้ (ถูกลบ/ไม่มีสิทธิ์) สคริปต์จะค้นตามชื่อ แล้วสร้างใหม่ให้เอง — ไม่ทำให้ระบบพัง
- โฟลเดอร์ต้องอยู่ใน Drive ของ**บัญชีที่ Deploy** (`Execute as: Me`) หรือถูกแชร์ให้บัญชีนั้นแบบ **ผู้แก้ไข** (Editor) ถ้าเป็นบัญชีอื่นและยังไม่แชร์ สคริปต์จะใช้โฟลเดอร์ชื่อเดียวกันที่มันสร้างเองแทน
- ตรวจสอบสิทธิ์ + ทดสอบอัปโหลด: Apps Script → เลือกฟังก์ชัน **`checkDrive`** → Run (▶) → ดูผลที่ **View → Logs** จะเห็น `✅ images` / `✅ slips` พร้อมลิงก์โฟลเดอร์และลิงก์ไฟล์ทดสอบ (ลบไฟล์ `test-*.png` ทิ้งได้)
- ไฟล์ที่อัปโหลดจะถูกตั้งสิทธิ์เป็น “ใครมีลิงก์ดูได้” และเก็บลิงก์แบบ `https://lh3.googleusercontent.com/d/<fileId>=w1600` ลงชีต (คลิกเปิดรูปจากชีตได้เลย)
- ในแอป: หน้า **จัดการคำสั่งซื้อ** และหน้า **ซิงก์ชีต** มีลิงก์ **📁 เปิดโฟลเดอร์สลิปใน Drive** ให้กดดูรวมได้ — ตั้งค่าที่ตัวแปร `SLIP_FOLDER_URL` ใน `js/config.js` (ให้ตรงกับ `FOLDERS.slips` ใน `gs/Code.gs`)

## ซิงก์กับ Google Sheet (สินค้า + คำสั่งซื้อ ขึ้น/ลง)
สร้างสเปรดชีตใหม่เองได้ง่าย ๆ เพราะ `gs/Code.gs` มีฟังก์ชัน `setup()` ที่สร้างแท็บ+หัวคอลัมน์+แท็บคู่มือภาษาไทยให้ครบทุกแท็บ (ครั้งเดียว ~2 นาที):
1. เปิด Google Sheets → **สร้างสเปรดชีตใหม่** → ตั้งชื่อ เช่น “LUKPAD DATA”
2. เมนู **ส่วนขยาย (Extensions)** → **Apps Script** → ลบทุกโค้ดเดิม → วางไฟล์ `gs/Code.gs` ทั้งหมด → Save
3. ที่ dropdown ของฟังก์ชันเลือก **setup** แล้วกด **Run (▶)** (ครั้งแรกกด Allow access) — จะได้แท็บ `PRODUCTS`, `ORDERS`, `ORDER_DETAILS`, `PAYMENTS`, `SHIPMENTS`, `USERS`, `คู่มือ` พร้อมหัวคอลัมน์และคำอธิบายแต่ละคอลัมน์เป็นภาษาไทย
4. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone** → Deploy แล้ว Allow access
5. คัดลอก URL (`https://script.google.com/macros/s/…/exec`) มาที่แอดมิน → เมนู **ซิงก์ชีต** → บันทึกลิงก์ → ทดสอบการเชื่อมต่อ

ทางเลือก (ไม่อยากใช้ `setup()`): copy หัวคอลัมน์จาก `db/sheet-template/*.csv` ไปวางที่แถว 1 ของแท็บที่สร้างเอง (มีวิธีในไฟล์ `db/sheet-template/วิธีใช้.txt`)

ใช้งาน:
| ปุ่ม/อากัปกิริยา | ผล |
|---|---|
| ⬆ อัปโหลดขึ้นชีต | เขียนสมาชิก/สินค้า/คำสั่งซื้อจากแอปทับแท็บ USERS, PRODUCTS, ORDERS, ORDER_DETAILS, PAYMENTS, SHIPMENTS และอัปโหลดรูปสินค้าเข้า Drive |
| ⬇ ดึงข้อมูลจากชีต | อ่านแท็บดังกล่าวมาทับ/รวมกับข้อมูลในแอป (อัปเดตเลข `nextOrder` / `nextProduct` / `nextUser` ให้เอง) |
| สมัครสมาชิกใหม่ | ส่งสมาชิกขึ้นแท็บ USERS ให้ **อัตโนมัติ** ทันที (เมื่อตั้งค่า URL แล้ว) |
| แก้ข้อมูลใน “บัญชีของฉัน” | ส่งข้อมูลสมาชิกขึ้นชีตให้อัตโนมัติเช่นกัน |
| เปิดเว็บครั้งแรก | ถ้าตั้ง `SHEET_URL` ไว้ แอปจะ **ดึงข้อมูลจากชีตล่าสุดให้อัตโนมัติ** สำหรับลูกค้า/ผู้เยี่ยมชม (แอดมินใช้ตัวจับเวลาดึงเองเพื่อไม่ให้ข้อมูลที่ยังไม่ push หาย) |
| ลูกค้าสั่งซื้อ / แนบสลิป / แอดมินเปลี่ยนสถานะ | ส่ง **ออเดอร์เดียว** ขึ้นชีตทันที (`action:"order"`) — ไม่ทับข้อมูลอื่น และสถานะที่แอดมินคีย์ไว้ในชีตจะไม่ถูกถอยหลัง |
| เปิดหน้า “จัดการคำสั่งซื้อ” หรือ “คำสั่งซื้อของฉัน” | **ดึงข้อมูลใหม่ให้เองทุก 20 วินาที** (มีปุ่ม “อัปเดตเดี๋ยวนี้” + ปุ่มเปิด/ปิด + แสดงเวลาอัปเดตล่าสุด) — ออเดอร์/สลิปใหม่เด้งเข้ามาเอง |
| เน็ตหลุดระหว่างส่ง | ออเดอร์ถูกเก็บไว้ในเครื่องพร้อมป้าย “ยังไม่ส่งขึ้นชีต” และระบบจะ **ลองส่งใหม่เองทุก ๆ 20 วินาที** จนสำเร็จ (ข้อมูลไม่หาย) |

### ซิงก์อัตโนมัติ (ใกล้เรียลไทม์)
- **ฝั่งลูกค้า**: สั่งซื้อ/แนบสลิปแล้วถูกส่งขึ้นชีตทันที หน้า “คำสั่งซื้อของฉัน” ยังดึงสถานะใหม่จากแอดมินเองทุก ~20 วินาที
- **ฝั่งแอดมิน**: หน้า **จัดการคำสั่งซื้อ** ดึงชีตเองทุก 20 วินาที → ออเดอร์/สลิปใหม่ขึ้นจอเอง ไม่ต้องกดปุ่ม (กด **อัปเดตเดี๋ยวนี้** ได้ทันที / **⏸ อัปเดตอัตโนมัติ** เพื่อหยุดชั่วคราวตอนกำลังแก้ข้อมูล)
- ระบบจะ**หยุดดึงเองชั่วคราว**ระหว่างพิมพ์ในฟอร์ม หรือเมื่อแท็บเว็บไม่ได้เปิดอยู่ (กันข้อมูลที่กำลังพิมพ์ถูกแทนที่)
- ต้องเปิดหน้าเว็บค้างไว้จึงจะรับข้อมูลได้ต่อเนื่อง — ถ้าปิดแท็บแล้วเปิดใหม่ แอปจะดึงล่าสุดให้เองตอนเปิด (`autoPull`)
- ⚠️ **ต้อง deploy ใหม่เมื่อแก้ `gs/Code.gs`**: เปิด Apps Script → วางโค้ดใหม่ → **Deploy → Manage deployments → Edit (ไอคอนดินสอ) → Version: New version → Deploy** (ลิงก์เดิมใช้ได้ต่อ) — ถ้าข้ามขั้นตอนนี้ การส่งออเดอร์ทีละใบจะใช้ไม่ได้และแอปจะขึ้นคำเตือน “สคริปต์ในชีตเป็นเวอร์ชันเก่า” ให้รู้ตัว

สคริปต์จะเพิ่มคอลัมน์ที่ขาด (เช่น `order_status`, `ship_address`, `carrier`, `tracking_number`, `updated_at`) ให้เองที่ปลายแถว และถ้าแก้ข้อมูลในชีตแล้วอยากให้แอปรับ ให้กด ⬇

**แต่งตั้งแอดมินเพิ่ม**: ในแท็บ USERS แก้คอลัมน์ `user_role` ของคนนั้นเป็น `admin` แล้วกลับไปที่แอป (ในเครื่องของคนนั้น) กด **⬇ ดึงข้อมูลจากชีต** — ระบบจะยกเป็นแอดมินให้ (คนที่ไม่ได้เป็น admin จะถูกปรับกลับเป็น customer เสมอ)

⚠️ ข้อควรทราบ: Web App URL เปิดให้ “Anyone” เขียนได้ (ตามข้อจำกัดของ Apps Script) และการตรวจสิทธิ์แอดมินทำที่ฝั่งหน้าเว็บ ใช้กับร้านเล็ก/งาน demo ได้ แต่ถ้าใช้งานจริงควรมี API + ตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ (ดูหัวข้อ “ขั้นต่อไป”)

## จะแก้อะไร ไปแก้ที่ไหน
| ต้องการ | ไฟล์ |
|---|---|
| เปลี่ยนชื่อร้าน/สี/ฟอนต์ | index.html, css/style.css |
| เพิ่ม/ลดสถานะคำสั่งซื้อ | config.js (`FLOW`) |
| เปลี่ยนตัวเลือก Custom หรือราคา | config.js (`CUSTOM`, `CUSTOM_FEE`) |
| เปลี่ยนบัญชีธนาคาร/สินค้าตั้งต้น | config.js (`seed`) |
| ตั้งค่า URL ชีตให้ทุกเครื่อง/ลูกค้าทุกคนใช้ร่วมกัน | config.js (`SHEET_URL`) |
| เปลี่ยนว่าใครซื้อได้/ใครดูได้ | app.js (`BROWSE`, `ADMIN_ONLY`) + การเช็กใน `submit` |
| ปรับการแสดง/เก็บสลิป | views-customer.js (`slipBox`) + app.js (event `data-slip`) + gs/Code.gs (`uploadImage_`) |
| เพิ่ม/เปลี่ยนวิธีซิงก์ชีต (คอลัมน์/แท็บ) | gs/Code.gs (`NEED`) และ js/sheet.js (`sheetPayload`/`sheetApply`) |
| รูปสลิป/รูปสินค้าแสดงในชีต (ขนาด/ปิด) | gs/Code.gs (`PREVIEW`, `imgFormula_`) · ลิงก์โฟลเดอร์สลิปในแอป: config.js (`SLIP_FOLDER_URL`) |
| โฟลเดอร์ Google Drive ที่เก็บรูป/สลิป | gs/Code.gs (`FOLDERS`) — ใส่ Folder ID หรือเว้นว่างให้สร้างตามชื่อ |
| เพิ่มหน้าใหม่ (เช่น รีวิวสินค้า) | เขียนฟังก์ชัน `vXxx()` ใน views-*.js แล้วลงทะเบียนใน `VIEWS` (app.js) และเมนูใน `nav()` |
| เพิ่มปุ่ม/ฟอร์มที่ทำงานได้ | จัดการใน app.js (`data-act` / `submit`) |
| สิทธิ์แอดมินเท่านั้น | app.js (`ADMIN_ONLY` และเช็ก `role` ตอน submit) |

## ขั้นต่อไปเมื่อใช้งานจริง
1. **ต่อฐานข้อมูลกลาง** ให้ลูกค้ากับแอดมินเห็นข้อมูลเดียวกัน: ใช้ `db/schema.sql` กับ MySQL หรือใช้ Supabase/Firebase แล้วเปลี่ยนการอ่าน/เขียน `DB` ใน store.js เป็นการเรียก API
2. **ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์**: การเช็ก role ในหน้าเว็บอย่างเดียวไม่ปลอดภัย การเปลี่ยนสถานะต้องผ่าน API ที่ตรวจว่าเป็น admin
3. **รหัสผ่าน**: เก็บเป็น hash (bcrypt) ไม่เก็บรหัสจริง
4. **สลิป**: ตอนนี้เก็บแค่ชื่อไฟล์สลิป ควรอัปโหลดไฟล์จริงไป storage แล้วเก็บ URL (รูปสินค้าทำแบบนี้แล้วผ่าน Google Drive ใน `gs/Code.gs`)
5. **API ที่ควรมี**: POST /auth/login, GET/POST/PUT/DELETE /products, POST /orders, GET /orders (ของตัวเอง), POST /orders/:id/slip, PATCH /orders/:id/status (admin), GET /users (admin)
